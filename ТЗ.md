# Техническое задание (ТЗ) на разработку программы оцифровки математических лекций

## 1. Описание проекта
**Название проекта:** AI Конвертер PDF $\to$ LaTeX (с поддержкой Gemini 3.1)
**Цель:** Автоматизированная программа на Python для конвертации конспектов и лекций (преимущественно по математике и механике) из формата PDF в компилируемый \LaTeX-документ с помощью нейросети Google Gemini.

## 2. Основной функционал (User Flow)
Программа должна выполнять следующий цикл действий:
1. **Загрузка и нарезка PDF:** Чтение входного `.pdf` файла и преобразование каждой его страницы в изображение с высоким разрешением (масштаб 2.0x).
2. **Оцифровка (AI Распознавание):** Отправка каждого изображения в нейросеть `gemini-3.1-flash-lite-preview` с инструкцией перевести содержимое в точный чистый \LaTeX код.
   * *Самопроверка AI:* Нейросеть за один проход оцифровывает и сразу проверяет себя на синтаксические ошибки (незакрытые фигурные скобки, знаки доллара и т.д.).
3. **Сборка итогового документа:** Соединение оцифрованных страниц, добавление единой $\LaTeX$-преамбулы, настроенной для верстки без переполнений.
4. **Глобальная проверка логики:** Отправка всего собранного сырого кода в ИИ для финальной проверки структуры (на предмет забытых закрытий блоков, окружений).
5. **Компиляция (Auto-Build):** Запуск системного компилятора `pdflatex`.
6. **Автоисправление ошибок компиляции (Self-healing):** Если при компиляции возникает ошибка, скрипт берет лог ошибки и сломанный код, отдает их обратно в ИИ. ИИ возвращает **точечные замены в формате JSON** (фрагмент кода до $\to$ фрагмент кода после), которые применяются к тексту, избегая переписывания всего документа (чтобы не упираться в лимиты по токенам при больших файлах). Процесс повторяется до 3 раз.
## 3. Технические требования и ограничения
### 3.1. Защита от переполнения (Overfull \hbox)
Из-за специфики математических рукописей часто получаются длинные формулы, которые вылезают за границы листа A4 при компиляции.
**Решение в программе:**
* В преамбулу добавлены пакет `microtype`, команды `\sloppy` и `\allowdisplaybreaks`.
* Настроены специфические `geometry` (поля: левое 2.5см, правое 1.5см).
* **Жесткий промпт ИИ:** Инструкция в обязательном порядке использовать окружения `align*`, `split` или `multline` из пакета `amsmath` для многострочных дробей и длинных выражений.

### 3.2. Rate Limits (Ограничения API)
Доступ к Google Gemini API (бесплатный тариф) ограничен 15 запросами в минуту (RPM).
**Решение в программе:**
* Реализован адаптивный класс `RateLimiter`. Он отслеживает точное время прошлого запроса к API и перед следующим запросом усыпляет поток на недостающее количество времени (стабилизируя скорость на уровне не более 1 вызова в 4 секунды).

### 3.3. Модель искусственного интеллекта
Требуется строгое использование экспериментальной модели: `gemini-3.1-flash-lite-preview`.

### 3.4. Парсинг графики
* Для простых геометрических или схематичных рисунков промпт предлагает ИИ описать их с помощью кода `TikZ`.
* В случае невозможности (или для сложных рисунков) ИИ оставляет в коде плейсхолдер: `% [Рисунок: описание]`.

## 4. Требования к окружению
* Язык: Python 3.9+
* Зависимости (указаны в `requirements.txt`):
  * `PyMuPDF` (библиотека `fitz`) — для работы с PDF.
  * `Pillow` — для обработки сырых пиксельных данных страниц.
  * `google-generativeai` — SDK для работы с Gemini.
  * `python-dotenv` — для безопасного хранения ключей доступа в файле `.env`.
* Система (для локальной компиляции): Обязательно наличие дистрибутива `MiKTeX` (для Windows) или `TeX Live` (Linux/Mac) с прописанным в системный `PATH` бинарником `pdflatex`.

## 5. Режимы работы программы через CLI
Скрипт должен поддерживать запуск через терминал с аргументами командной строки:
* `python main.py <вход.pdf> <выход.tex>` — Полный цикл (оцифровка, сборка, проверка, компиляция с автопочинкой).
* `python main.py --check-only <выход.tex>` — Взять готовый $\LaTeX$-файл, прогнать через ИИ для устранения логических ошибок и скомпилировать.
* `python main.py --compile-only <выход.tex>` — Игнорировать проверки до компиляции. Сразу запустить `pdflatex`, а в случае падения — отдать лог на починку ИИ.
